Abstract

Autonomous artificial intelligence (AI) coding and systems-operations agents increasingly execute build toolchains, browsers, shell commands, and untrusted third-party dependencies directly on developer workstations and edge Linux servers. Traditional enterprise hardening baselines—such as CIS Benchmark Level 2, Linux kernel lockdown, global disabling of unprivileged user namespaces (userns), and default auditd kernel buffers—frequently break rootless sandboxes or drop forensic telemetry during high-frequency agent tool invocations. This technical report introduces and delivers the Kether_1 Framework, a reproducible six-layer defense-in-depth architecture targeting Debian 13 (Trixie, Linux Kernel 6.12 LTS). The framework resolves the tension between strict Zero Trust confinement and autonomous agent execution through: (1) deployable baselines across sysctl, selective userns AppArmor 4.x confinement, default-deny nftables with lateral KVM bridge isolation, ordered lossless auditd (-b 8192, immutable -e 2), DNS-over-TLS, and post-quantum hybrid OpenSSH 10; (2) an idempotent Copy-on-Write (CoW) QCOW2 ephemeral KVM sandbox orchestrator enforcing read-only golden backing images with SHA-256 post-teardown integrity proofs; (3) a privilege-aware, strongly typed JSON six-layer telemetry collector and 43-control CIS/BeyondCorp auditor; and (4) a transparent comparative experimental protocol and continuous integration test suite.

Keywords: Debian 13, Linux kernel hardening, Zero Trust, BeyondCorp, CIS Benchmark Level 2, AppArmor userns, ephemeral KVM sandbox, QCOW2 Copy-on-Write, auditd, autonomous AI agents.
